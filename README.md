# bracetree

Brace CSV/TSV tree tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/bracetree/

## Install / run

```bash
git clone https://github.com/theworker02/bracetree.git
cd bracetree
node src/cli.js
node --test
```
